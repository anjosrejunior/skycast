# 🌤️ SkyCast - Weather Forecast App

A sleek, responsive weather dashboard built with **Vanilla JavaScript**, **Vite**, and **Tailwind CSS**. This application allows users to fetch real-time weather data by providing precise geographical coordinates (Latitude and Longitude).

![Project Demonstration](/banner.png)
> **How it works:** Enter your coordinates (e.g., Lat: 52.52, Lon: 13.41), hit "Send", and watch the interface update with current sky conditions and temperature.


## 🔧 Features

- **Real-time Weather Data**: Integrated with the Open-Meteo API.
- **Dynamic UI**: Displays weather conditions, temperature, and "Feels Like" (apparent temperature) dynamically.
- **Smart Mapping**: Uses a custom Weather Dictionary to translate WMO codes into readable English conditions and icons.
- **Fully Responsive**: Optimized for all devices using Tailwind's Mobile-First approach.

## 🤖 Technologies Used

* [Vite](https://vitejs.dev/) - Ultra-fast build tooling.
* [JavaScript (ES6+)](https://developer.mozilla.org/en-US/docs/Web/JavaScript) - Pure logic, no frameworks.
* [Tailwind CSS](https://tailwindcss.com/) - Utility-first styling.
* [Open-Meteo API](https://open-meteo.com/) - Weather API

## ⚙️ Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/skycast.git
    cd skycast
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```
